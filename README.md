# YT Morphe

YT with all [Morphe](https://github.com/MorpheApp/morphe-patches) patches, voice-over translation, a built-in video and audio downloader and ready-made settings.

[![Latest release](https://img.shields.io/github/v/release/RAMiK4/yt-morphe?label=Download&sort=date&style=for-the-badge)](https://github.com/RAMiK4/yt-morphe/releases/latest)

</div>

## 🌟 Features

| | |
|---|---|
| 🧩 **All Morphe patches for YT** | Built on the official Morphe patches, which are never modified |
| 🗣️ **Google and Yandex voice-over translation** | Listen to videos in your language (VoT) |
| ⬇️ **Video, audio, thumbnail and subtitle downloader with Save to device and offline SponsorBlock** | Download videos, audio (Opus / M4A), thumbnails and subtitles (SRT / VTT, also auto-translated) as files with a quality picker, and watch them offline with subtitles and SponsorBlock skipping: *Morphe settings → Player → Save to device* |
| ⚙️ **Customizable preset settings** | A Premium-like experience from the first start. Your own changes are always kept |
| 🏝️ **Extra clone variant** | Dynamic Island on supported devices |
| 🔔 **In-app update check** | New builds are shown in the app: *Morphe settings → Updates* |

The changes of each version are listed in the [releases](https://github.com/RAMiK4/yt-morphe/releases).

## 📱 Variants

| Variant | |
|---|---|
| **Amoled** | Pure black / white by default, Material and other themes |
| **Original** (BBK Clone) | Modern dark / soft light by default, Material and other themes, plus BBK Dynamic Island for BBK cn devices |

Both variants can be installed side by side. Theme colors can be changed at any time: *Morphe settings → General*.

## 📥 Install

1. Download the APK of your variant from the [latest release](https://github.com/RAMiK4/yt-morphe/releases/latest).
2. Install it. To sign in with a Google account, [MicroG-RE](https://morphe.software/microg) is required.

Updates install over the previous version without losing data.
